APSODIA VI

Trois talents, une campagne. Prépare le pitch avec Justin, débloque les dossiers avec Enzo et réalise les photos avec Lana pour lancer BRIZ.

À tester sur ordinateur, avec clavier et souris.

Commandes et missions BRIZ

Lobby : survol et clic sur un personnage, ou 1 / 2 / 3 puis Entrée. B affiche le brief. Les missions se jouent dans l’ordre de ton choix ; ta progression est conservée sur ce navigateur.
Bureau : ZQSD / WASD / flèches, Maj pour courir. Clique dans le jeu pour regarder avec la souris ; Échap la libère. Rejoins le repère coloré et appuie sur E. L revient au lobby hors mission.
Justin : rejoins le canapé, choisis trois cartes avec 1 à 6, confirme avec Entrée et réponds au client avec 1 / 2 / 3. Budget : six jetons.
Enzo : rejoins ses écrans. TRAMONTAGNE : ← → déplacer, ↑ / X pivoter, Z rotation inverse, ↓ descendre, Espace chute, C réserve. Efface six lignes.
Lana : rejoins le tableau blanc. Flèches pour cadrer, + / - ou molette pour zoomer, Espace pour photographier. Les curseurs permettent aussi de régler le cadre.
Dans les missions : P pour mettre en pause, Échap pour revenir au bureau. Le bouton SON coupe les effets. Réussis les trois missions pour découvrir le bilan de campagne.
