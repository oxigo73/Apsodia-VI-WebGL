APSODIA VI

Trois talents, une campagne. Prépare le café avec Justin, débloque les dossiers avec Enzo et réalise les photos avec Lana pour lancer BRIZ.

À tester sur ordinateur, avec clavier et souris.

Commandes et missions BRIZ

Lobby : survol et clic sur un personnage, ou 1 / 2 / 3 puis Entrée. B affiche le brief. Les missions se jouent dans l’ordre de ton choix ; ta progression est conservée sur ce navigateur.
Bureau : ZQSD / WASD / flèches, Maj pour courir. Clique dans le jeu pour regarder avec la souris ; Échap la libère. Rejoins le repère coloré et appuie sur E. L revient au lobby hors mission. F utilise les chaises, le canapé et le tableau ; T commande la télévision pendant une pose. Au tableau : maintenir Espace pour écrire, R pour effacer.
Justin : rejoins la machine dans le sas d’entrée. En vue subjective, déplace la main avec la souris ou les flèches ; Clic / Espace pour saisir, verser et appuyer. Remplis le réservoir, insère une dosette puis lance le café. La main tremble davantage avec le temps.
Enzo : rejoins ses écrans. TRAMONTAGNE : ← → déplacer, ↑ / X pivoter, Z rotation inverse, ↓ descendre, Espace chute, C réserve. Efface six lignes.
Lana : rejoins le tableau blanc. Flèches pour cadrer, + / - ou molette pour zoomer, Espace pour photographier. Glisse dans la photo pour ajuster le cadrage ; les indicateurs te guident.
Dans les missions : P pour mettre en pause, Échap pour revenir au bureau. Le bouton SON coupe les effets. Réussis les trois missions pour découvrir le bilan de campagne.
